STEP 5 — 좌석 등록 ⭐ 가장 중요
5
좌석 설정 팝업에서 등급·위치·구역 등록
카테고리 목록 → 해당 카테고리 "좌석설정" 버튼 클릭
진입 방법: 카테고리 저장 후 목록에서 해당 카테고리의 좌석설정 버튼 클릭 → 팝업 창으로 열림
URL 예시: re-adm.ticketbay.co.kr/product/category/seat/{id}?popup=true
팝업 화면 구성 (4개 컬럼)
① 등급
티켓 등급명
② 적용
가격 입력
③ 위치
좌석 유형
④ 구역
세부 구역명
① 등급 검색 예매사 페이지의 티켓 등급명을 검색창에 입력 → 검색
예) VACCINE ZONE, 선예매, 일반예매, VIP-SOUND CHECK 등
② 적용 + 가격 해당 등급 체크박스 선택 → 오른쪽 가격란에 금액 입력
예) PANDEMONIUM ZONE: 121000 / VACCINE ZONE: 121000
③ 위치 검색 좌석 유형 검색 (예매사 좌석 배치도 참고)
예) floor → 플로어 스탠딩석 / 계단식 → 계단식 좌석(tiered seats)
④ 구역 선택 구역 검색창에 구역명 입력 후 체크박스 선택
예) P1, P2, P3... / 1구역, COME, BACK, HOME 등
공연 좌석배치도와 비교하며 해당 구역 모두 체크
예시 ① — P1Harmony (피원하모니 2026 - 고양)
등급 PANDEMONIUM ZONE 121,000원   VACCINE ZONE 121,000원
위치 플로어 스탠딩석 / 계단식 좌석(tiered seats) — 검색어로 조회
구역 P1, P2, P3, P4, P5, P6, P7, P8 등 공연 배치도 기준 구역 체크
예시 ② — 82MAJOR (82MAJOR 2026 - 서울)
등급 선예매 99,000원   일반예매 110,000원
VIP-GROUP PHOTO, VIP-SOUND CHECK, FLOOR석, 스탠딩 GA1/GA2 등 해당 공연 등급 모두 등록
위치 플로어 스탠딩석 / 공연 유형에 맞는 위치 선택
구역 1구역, COME, BACK, HOME, STANDING E 등 배치도 기준

우측 상단 "저장" 버튼으로 좌석 등록 완료

저장 후 팝업 창을 닫으면 됩니다

  • 예매사 공연 페이지의 좌석 배치도 이미지를 반드시 참고하여 구역을 매핑하세요.
  • 등급명은 예매사 표기 기준으로 검색 — 일부 약어로도 검색 가능 (예: "floor", "p1", "예매" 등)
  • 구역이 없는 경우 하단 한글명 / 영문명 입력 후 "등록" 버튼으로 신규 추가할 수 있습니다.
주의사항
  • 공연기간 상세는 회차별 시작 시간 기준으로 등록하세요. 종료 시간이 아닙니다.
  • 카테고리 세부구분은 B로 고정합니다. (기존 케이스 참고)
  • 영문·중문·일문 카테고리명 필드는 비워두지 말고 하이픈(-)을 입력하세요.
  • 해외 공연이 아닌 경우 해외 전시 유무는 항상 미사용으로 설정합니다.
  • 동일 아티스트의 기존 카테고리가 있을 경우, 2Depth 선택창에서 기존 아티스트 선택 후 신규 공연만 추가합니다.
